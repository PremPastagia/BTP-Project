# Submission checklist
- [ ] Research question, estimand and hypotheses recorded.
- [ ] Search strategy, screening decisions and source types recorded.
- [ ] Citations verified; APA and BibTeX agree.
- [ ] Sources, permissions, licenses, dates, vintages and hashes recorded.
- [ ] Data dictionary and observed/derived/imputed/synthetic labels complete.
- [ ] Cleaning and exclusions justified; quality diagnostics reviewed.
- [ ] Analysis plan and changes timestamped.
- [ ] Appropriate simple baselines evaluated.
- [ ] Training-only transformations and release-delay leakage checks pass.
- [ ] Groups/time dependence handled; final test untouched during selection.
- [ ] Metrics, uncertainty and model comparisons justified.
- [ ] Code, seeds, environment and dependencies captured.
- [ ] Results trace to actual reproducible runs; failed runs retained.
- [ ] Limitations, validity threats and extensions reported.
- [ ] Independent reproduction command and required access documented.
