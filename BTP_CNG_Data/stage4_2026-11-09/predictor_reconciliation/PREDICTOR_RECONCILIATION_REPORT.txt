2. LEGACY NUMERICAL FIELDS

The audit compared13,596 legacy predictor cells with same-period native records
across explicitly labelled versions;10,524 comparisons have an exact value match
to at least one native source vintage. These are repeated comparison operations,
not counts of unique recovered observations. A matching value does not prove its
release date, source version, geography, or real-time availability.

Actual source-code findings:
- External predictors are placed on a monthly grid, forward-filled and shifted.
  The blanket publication date is constructed by adding one month and12days
  to the month-start; it is not extracted individually from each source release.
- The annual GDP table has26 records. All26 assigned May 31release dates precede
  their own December 31observation-year ends. The code simultaneously describes
  a151-day lag, but assigns the same year's May 31. These dates cannot validate
  historical availability of the current-vintage annual estimates.
- The monthly GDP column holds annual values under an assumed year/May rule.
  It is not a new observed monthly GDP series or a recovered historical vintage.
- All179 nonmissing paired FX rows have identical mean and month-end fields.
  The code assigns the same Yahoo monthly closing value to both. Mean is an
  unsupported label. The source timezone/DST month-decoding issue also remains
  relevant in the old grid; the corrected native series is separate.
- The field called TTF is sourced from the World Bank Europe natural-gas
  benchmark. Its precise source definition must be retained; it is not silently
  equated to a standalone TTF spot series.
- Dubai, WTI, Europe gas and Japan LNG each repeat their December 2024 value in
  all22 grid rows from January 2025through October 2026. The source code explicitly
  forward-fills these fields. Brent and US gas have other source updates, so the
  same blanket repetition claim is NOT made for those fields.
- VAT and gas-policy histories include code-defined values; petrol/diesel,
  cross-fuel spreads/ratios and lagged fields depend on source/timing assumptions.
  Existing one-month shifts do not supply missing historical release evidence.
- Synthetic/unobserved VAHAN fields are excluded from empirical inputs. They
  appear only in an eligibility dictionary identifying the exclusion; no
  synthetic series values, distributions or model features were used.

The dictionary records each legacy field and each native variable/unit/geography/
frequency/source-vintage group. No current annual/quarterly value was expanded
into a fictional monthly measurement.

3. THE 799CORPORATE RECORDS ARE NOT799DATED TEXT DOCUMENTS

The legacy corpus has799 unique disclosure IDs and758 distinct nonempty attachment
filenames. Its collection code requests page1only for16 company/year query windows.
Fifteen company/year groups contain exactly50 rows and one contains49. This is a
page-limited discovery sample, not a complete company-report archive.

Only one row is marked locally downloaded. Its observation/dissemination claim
is17October 2024, but the linked bytes are the IGL November 2024allocation letter.
The code attaches that November PDF whenever an IGL headline contains an
allocation/reduction keyword, rather than matching the actual attachment ID.
The dated October row therefore cannot establish publication of that November
document. corporate_reconciliation.csv preserves the concrete mismatch and PDF
date evidence. No historical features were created from that link.

All799dissemination timestamp strings lack an explicit timezone. The code uses
the API NEWS_DT field and does not preserve original BSE response JSON here.
The records remain useful retrieval leads, but field names and downloaded flags
are not independent exchange-time/document-identity verification.

The accepted native corpus contains251deduplicated document metadata records,
whose exact raw bytes and aliases are separate from public-release evidence.
They remain excluded as dated historical predictors. This audit does not infer
publication time from a reporting year, a letter date or the current download.
